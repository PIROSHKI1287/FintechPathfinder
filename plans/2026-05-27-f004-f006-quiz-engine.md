## パラメータ設計
```
compliance: 初期100, 範囲[0,100]。0になるとゲームオーバー
gmv:        初期0,   範囲[0,∞)。下限0でクランプ
ux:         初期100, 範囲[0,100]
合格ライン: 全問回答 + compliance > 0 → isLevelCleared = true
```

## クイズ回答フロー
```
[クライアント] 選択肢クリック
  → POST /api/quiz/answer { questionId, chosenChoiceId, levelId }
  → [サーバー]
     1. questionId が levelId に属するか検証
     2. chosenChoiceId が questionId に属するか検証
     3. getProgressForLevel でパラメータ取得（未記録なら初期値）
     4. デルタ適用 + クランプ
     5. compliance=0 → isGameOver=true
     6. QuizAttempt 保存
     7. saveOrUpdateProgress でパラメータ更新
     8. 全問回答チェック → isLevelCleared
  → { isCorrect, feedbackText, params, isGameOver, isLevelCleared, answeredCount, totalCount }
[クライアント] ゲージ更新 → フィードバック表示 → 次の問題 or 遷移
```

## セキュリティ注意
- GET /api/levels/[id]/quiz の choices に isCorrect・delta を含めない
- パラメータ計算は全てサーバーサイド（.clauderules 準拠）
- quiz エージェントは user_progress に直接 Prisma クエリしない
  → getProgressForLevel / saveOrUpdateProgress を game-level/logic から import
