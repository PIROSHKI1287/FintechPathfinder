## F008 同意フロー設計

同意チェックは Edge Middleware から DB を直接叩けないため **cookie ベース** で実装。

```
[ログイン成功]
    → /home へリダイレクト
    → bpsp_consent cookie がない場合 → DisclaimerModal を表示
    → ユーザーが「同意する」クリック → POST /api/consent
    → DB に DisclaimerConsent 記録 + bpsp_consent=session cookie をセット
    → modal 閉じる → ゲーム利用可能

[ゲームページへの直接アクセス]
    → middleware.ts が bpsp_consent cookie を確認
    → cookie なし → /home へリダイレクト（モーダルが表示される）
```

## セキュリティ考慮
- bcryptjs saltRounds=12（.clauderules 準拠）
- registerSchema（Zod）でサーバーサイド検証
- パスワードはレスポンスに含めない
- bpsp_consent は HttpOnly/SameSite=Lax のセッション cookie
