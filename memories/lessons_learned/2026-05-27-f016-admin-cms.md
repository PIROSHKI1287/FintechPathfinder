## 実装概要

`/admin/content` に座学ページ・クイズ・辞書のGUI管理機能を実装した。

## 正常に動作したパターン

- `requireAdmin()` ガードを `agents/admin/api/_guard.ts` に切り出して全ハンドラーで再利用 → DRYかつ漏れなし
- `middleware.ts` に `/api/admin` を `ADMIN_PATHS` に追加して二重防衛（middleware + ガード）
- `next/dynamic` で LevelTab / DictionaryTab を動的インポート → SSRを避けてclient-onlyを明示

## Reviewerで指摘されたパターン

Reviewer から「r.ok チェック漏れ（Medium×複数）」を指摘された。
具体的には:
- `fetch(..., { method: 'DELETE' })` の戻りを未チェック
- `load()` 関数で `!r.ok` を無視して `.json()` を呼ぶ

**教訓**: fetch呼び出し後は必ず `if (!r.ok)` チェックを書く。
DELETE は `alert()` でエラーを通知、mutation は `try-catch + setError` パターン、
load は早期returnしてエラーステートを設定する。

## 避けるべき設計

- 1コンポーネントに全CRUD詰め込み → 今回はファイル分割（LevelTab / DictionaryTab）が機能した
- `useState` での削除/更新エラーを無音でスキップ → ユーザーが混乱する
