## 実装概要

BPSP_knowledge_base.md（2026年5月版）を一次情報源として、Level 1〜5の座学ページ（計23ページ）とクイズ問題（計17問）を `prisma/seed-content.ts` として実装した。

## 正常に動作したパターン

- `findFirstOrThrow({ where: { levelNumber: N } })` で Level ID を取得 → seed.ts のような `update: {}` 問題を回避
- `storyPage.upsert` は `levelId_pageNumber` の複合ユニーク制約を使用 → 冪等に動作
- `quizQuestion.upsert` で `update: { questionText, sortOrder }` を明示 → dev-q1-l1〜dev-q3-l1 のテキストが確実に差し替わった
- `quizChoice.deleteMany + createMany` で選択肢を完全差し替え → QuizAttempt.chosenChoiceId が String（FK制約なし）のため安全

## コンテンツ設計の判断

- Level 2 にゲームオーバー問題を配置（クロスボーダー収納代行の無許可承認: complianceDelta: -100）
- Level 1 のゲームオーバー問題（dev-q3-l1）は通常の誤答に置き換え → Level 1 は入門なのでゲームオーバーリスクを除去
- 手数料・LTV/CAC・GMV等の数値はBIPSA知識ベースの「業界目安の幅」として記載（特定事業者の実数値は断定しない）

## 次回への注意

- dev seed（seed-dev.ts）の quizQuestion.upsert は `update: {}` で内容を更新しない設計 → content seed は必ず `update: { questionText, sortOrder }` を入れる
- content-q4-l1 のような新規問題 ID は dev seed に存在しないため、create 側のみで動作する → upsert で問題なし
