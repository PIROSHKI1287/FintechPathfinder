## 主な学び

### Next.js typedRoutes と動的文字列
- `typedRoutes: true` の環境では `router.push(str)` や `<Link href={str}>` に生の `string` 型を渡すと TS エラーになる
- 既存コンポーネントはリテラル文字列を使うため型推論が通るが、変数経由の文字列は `as Route` キャストが必要
- `import type { Route } from 'next'` してキャストする

### (route-group)/layout.tsx の追加
- `app/(game)/layout.tsx` を追加するだけで (game) グループ配下の全ページに layout が適用される
- ConsentGate など各ページ固有のラッパーは維持したまま、共通ヘッダーだけを layout で追加できる
- Server Component として auth() を呼び、user 情報を Client Component の GlobalNav に props で渡すパターンが適切
