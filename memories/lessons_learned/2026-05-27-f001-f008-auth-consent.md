# 2026-05-27 — F001/F008-consent 認証・免責事項実装

## 学んだこと

### Edge Middleware と DB クエリの非互換
Next.js Edge Middleware（middleware.ts）は Edge Runtime で動作するため Prisma（Node.js API）を直接呼び出せない。
同意チェックを middleware で行うには **セッション cookie** を使う必要がある。

**対策:** `bpsp_consent=1` を HttpOnly/SameSite=Lax のセッション cookie として POST /api/consent 時にセット。
Middleware は cookie 値のみ確認するため DB クエリ不要。

### Server Component から cookies() を使う場合は await が必要（Next.js 15）
`cookies()` は Next.js 15 以降 async になった。`const cookieStore = await cookies()` とすること。

### authorize の dynamic import で循環参照を回避
`core/auth/auth.ts` は `agents/auth/logic/authorize` を静的 import すると循環依存のリスクがある。
dynamic import `const { authorizeCredentials } = await import(...)` で回避した。
