## 学んだこと

### useSearchParams は Suspense でラップしないとビルドエラー
GameOverScreen は `useSearchParams()` を使う Client Component。
Next.js の Static Rendering では useSearchParams が Suspense 境界を要求する。
`<Suspense fallback={...}><GameOverScreen /></Suspense>` でラップすること。

### quiz エージェントの user_progress 依存の解決方法
.clauderules で user_progress への直接クエリ禁止 → game-level/logic/progress の
`getProgressForLevel` / `saveOrUpdateProgress` を import するパターンで解決。
エージェント間の境界を破らずにデータ共有できる。

### processAnswer の「全問回答チェック」は distinct で
`QuizAttempt` に unique 制約がないため同じ問題に複数回答できる。
`findMany({ distinct: ['questionId'] })` で重複を除いた回答済み問題数を取得する。

### isCorrect をクライアントに「回答前に」渡さないこと
GET /api/levels/[id]/quiz の Prisma select で `isCorrect` と delta 系フィールドを
意図的に除外している。将来修正する際はこのレイヤーを崩さないこと。
