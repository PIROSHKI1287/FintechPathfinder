# 2026-05-27 — F002/F003/F007 学習進行度・座学・辞書実装

## 学んだこと

### Server Component から logic を直接呼ぶのが最適
LearnPage (Server Component) → getLevelStory() を直接呼ぶパターンは、
自分の API エンドポイントを fetch する二重往復を避けられて効率的。
Client Component が外部からデータを必要とする場合のみ fetch を使う。

### isUnlocked チェックを N+1 にしない工夫
getLevelsWithProgress で全レベルをループして isLevelUnlockedForUser を呼ぶと
N+1 クエリが発生する可能性がある。現フェーズではレベル数が少ない（5件）ため許容。
レベル数が増えた場合は前レベルを一括 JOIN するよう最適化すること。

### isPublished と isUnlocked の2軸管理
コンテンツが BLOCKED 状態でも「ロック解除済みだがコンテンツ準備中」を UI で表現できる。
isPublished=false → ボタンを「コンテンツ準備中」に変える。
これにより F009-F013 のコンテンツ解禁後も UI 変更なしで動作する。
