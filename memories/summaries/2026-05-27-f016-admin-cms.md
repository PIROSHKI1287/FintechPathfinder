# F016 管理者コンテンツCMS 実装計画

- **タスクID**: f016-001
- **作成日**: 2026-05-27
- **担当エージェント**: admin
- **優先度**: Could / Phase 1.5

## 目的

社内識者がGUIでコンテンツ（座学テキスト・クイズ・辞書）を編集・追加できる管理画面を実装する。
F009-F013 のコンテンツ投入が可能になる。

## スコープ

| 機能 | 詳細 |
|---|---|
| レベル管理 | isPublished トグル、タイトル/説明編集 |
| 座学ページ管理 | ページの追加・編集・削除（heading + body + diagramUrl） |
| クイズ管理 | 問題の追加・編集・削除 + 選択肢CRUD |
| 辞書管理 | 用語の追加・編集・削除 |

## セキュリティ設計

1. middleware.ts: `/api/admin` を ADMIN_PATHS に追加 → role=admin チェック
2. 全 API ハンドラー: `requireAdmin()` で二重チェック（Defense in Depth）
3. isPublished トグル: GUI操作（人間のみ）なので許可

## 除外（スコープ外）

- IPアドレス制限・2FA（詳細設計未決定のため）
- レベル新規作成（DB直接投入が基本フロー）
- メディアアップロード（diagramUrl は文字列入力のみ）
