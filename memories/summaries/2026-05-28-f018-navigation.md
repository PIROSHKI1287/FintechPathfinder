## 現状

- `app/(game)/` に layout.tsx が存在しない（各ページが独立した `<main>` を持つ）
- グローバルヘッダー・ナビゲーションなし
- 戻るボタン・パンくずなし
- `agents/_shell/ui/` は空（.gitkeep のみ）

## 実装方針

### 追加ファイル
1. `agents/_shell/ui/GlobalNav.tsx` — クライアントコンポーネント
   - `usePathname()` でルートを判定
   - 戻るボタン（コンテキスト依存）
   - パンくずテキスト
   - グローバルナビリンク（ホーム・辞書・履歴）

2. `app/(game)/layout.tsx` — サーバーコンポーネント
   - `auth()` でセッション取得 → GlobalNav に user 情報を渡す
   - `<header>GlobalNav</header>` + `{children}` を返す

### ルート別の戻るボタン先とパンくず

| ルート | 戻るボタン先 | パンくず |
|---|---|---|
| /home | なし | ホーム |
| /game/[N]/learn | /home | ホーム > Level N > 座学 |
| /game/[N]/quiz | /game/[N]/learn | ホーム > Level N > クイズ |
| /game/[N]/result | /home | ホーム > Level N > 結果 |
| /game/game-over | /home | ホーム > ゲームオーバー |
| /dictionary | /home | ホーム > 用語辞典 |
| /history | /home | ホーム > 学習履歴 |
| /settings | /home | ホーム > 設定 |

### レイアウト設計
```
┌─────────────────────────────────────────────────────┐
│ ← 前の画面  BPSP育成ゲーム    ホーム 辞書 履歴  │  ← sticky header (h-14)
├─────────────────────────────────────────────────────┤
│ ホーム > Level 1 > 座学                              │  ← breadcrumb bar
├─────────────────────────────────────────────────────┤
│                                                     │
│              {children}                             │
│                                                     │
└─────────────────────────────────────────────────────┘
```

モバイル（375px）では breadcrumb を省略しパンくずを header 内に収める。

### 変更しないもの
- 各ページの `<main className="min-h-screen p-8">` は維持（layout が header を追加するだけ）
- `ConsentGate` は home/page.tsx 内に残す
- `/admin/*` は (game) グループ外なので影響なし
